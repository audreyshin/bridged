# BridgED

Website for [BridgED](https://github.com/audreyshin/bridged), a fiscally sponsored 501(c)(3) nonprofit teaching disability awareness and running community clinics.

## Run locally

From this folder:

```bash
python3 -m http.server 43147
```

Then open [http://127.0.0.1:43147](http://127.0.0.1:43147).

Or open the folder in VS Code / Cursor and start editing `index.html`, `about.html`, `work.html`, and `style.css`.

## Pages

- `index.html` — home
- `about.html` — Kathryn Shin and six cofounder cards
- `work.html` — photo gallery with empty slots for new pictures
- `information.html` — disability explainers
- `resources.html` — videos, books, clubs
- `contact.html` — Kathryn’s email and Instagram

Add new event photos to `images/`, then point one of the dashed “Add a photo” slots at the file.
