# BridgED

Website for [BridgED](https://github.com/audreyshin/bridged), a fiscally sponsored 501(c)(3) nonprofit teaching disability awareness in Ridgewood, New Jersey.

## Preview

This Cloud Agent is serving the site at:

**http://127.0.0.1:43147**

On your own computer:

```bash
python3 -m http.server 43147
```

Then open [http://127.0.0.1:43147](http://127.0.0.1:43147).

## Pages

- `index.html` — home
- `about.html` — Kathryn Shin and six cofounder cards
- `work.html` — photos from BridgED workshops and exhibits
- `information.html` — disability explainers and source statistics
- `resources.html` — videos, books, clubs
- `contact.html` — Kathryn’s email and Instagram
